Yonru Clip **v0.2.0** brings **Styles Preset & Kinetic Captions** featuring real-time kinetic caption animation preview, custom preset indicators, casing synchronization, and workspace preview isolation.

  - Add PresetStudioViewport with kinetic animation engine (#303)
  - Deferred render autoplay, studio control deck, and workspace preview isolation (#295)
